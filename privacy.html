Privacy Policy

Last updated: October 7, 2026

Studio is a personal application used only by its owner to manage the owner's own YouTube channels.

What data the app accesses

With the owner's permission through Google OAuth, the app uses the YouTube Data API and YouTube Analytics API to upload the owner's videos and thumbnails, set their titles, descriptions and publication schedule, and read statistics of the owner's channels (views, subscribers, likes, comments count).

How data is stored

OAuth tokens and channel statistics are stored only on the owner's own computer. No data is sent to any third-party server, sold, shared or used for advertising.

Google API Services

Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
